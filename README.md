## 🚀 Proyectos Destacados

### 🏢 [El Club de la Ingeniería - Plataforma Web Oficial](https://github.com/IngMarlonPerez/El-Club-de-la-Ingenier-a)
> Plataforma modular desarrollada con **Next.js**, **React**, y **Supabase** que integra la gestión de miembros, inicio de sesión social y **Operación Laboratorio-B** (un simulador interactivo de consola Linux de 31 niveles con asistente de voz holográfico impulsado por IA).
*   **Tecnologías:** Next.js, JavaScript, Tailwind/CSS, Supabase, Web Audio API, Groq/Llama-3.

### 🧠 [Asistente de IA Holográfico - INGenioso](https://github.com/IngMarlonPerez/El-Club-de-la-Ingenier-a) *(Parte del ecosistema del Club)*
> Un agente conversacional inteligente integrado en terminales web con capacidades de respuesta local por fallback, síntesis de voz interactiva y retroalimentación en tiempo real para guiar a los estudiantes en desafíos técnicos de sistemas operativos.
*   **Enfoque:** Inteligencia Artificial, Procesamiento de Lenguaje Natural (NLP).
